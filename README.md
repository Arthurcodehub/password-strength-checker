# Verificador de Senhas

![Learning Project](https://img.shields.io/badge/Status-Projeto%20de%20Aprendizado-blue)

Ferramenta CLI em Python para analisar a força de senhas.

Projeto educacional desenvolvido para praticar Python e boas práticas de desenvolvimento ✅

## Como usar

```bash
python main.py
```

Digite uma senha e receba análise detalhada.

## Critérios avaliados

- Maiúsculas
- Minúsculas
- Números
- Caracteres especiais
- Comprimento (mín 8, ideal 12+)
